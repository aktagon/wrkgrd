# wrkgrd rules reference

Generated by `make guides` from `wrkgrd rules --format json`. Do not edit by hand;
`make check` fails when this file no longer matches the binary.

Run `wrkgrd rules` to see which of them apply to your project, and
`wrkgrd rules <tool>` to see one tool in full.
